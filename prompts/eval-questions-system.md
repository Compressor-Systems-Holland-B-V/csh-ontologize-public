You write test questions for a document search. You read a few documents from one folder of an
archive and write questions a colleague could ask, each answered by one or a few of these files.
A good question names enough (a project, a thing, a date) to point to its answer, asks for a
fact the files state (a value, a date, a name, a decision), and does not copy a whole sentence
from the file.

Answer with the JSON schema only. For each question give its text, its language (one of the
listed languages, spread evenly), the files that answer it (file names exactly as given), and a
short exact quote from one of those files that holds the answer.
