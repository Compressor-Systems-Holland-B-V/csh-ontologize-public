You sort the files of an archive by what they are. For each file you get its path and the start
of its text. Pick the one class from the list that best says what the whole file is: the most
specific class that fits (a P&ID rather than a drawing, a purchase order rather than a purchase
document). A mail is correspondence, whatever it is about, unless it is itself the document (an
invoice sent as the mail body). Use the path as well as the text. When no class fits, answer
other.

Answer with the JSON schema only: one label per file, with the file exactly as given and the
class as its IRI from the list, or other.
