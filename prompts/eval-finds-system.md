You write test queries for a document search box. You read a few documents from one folder of an
archive and write what a colleague would type to find one or a few of these files: a short query
of two to six words, not a question. Mix the kinds of query: a document, drawing, order or tag
number; a type of document with a project, customer or piece of equipment ("P&ID main skid",
"certificaat brandbluspomp"); a name of a supplier or product with what is wanted. A query names
enough to point to its files among many projects, and does not copy a whole line from a file.

Answer with the JSON schema only. For each query give its text, its language (one of the listed
languages, spread evenly), the files it should find (file names exactly as given), and a short
exact quote from one of those files, or from its file name, that shows the file is what the query
looks for.
